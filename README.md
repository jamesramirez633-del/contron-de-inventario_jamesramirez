 Descripción del programa

Este programa fue desarrollado en C# como una aplicación de consola para controlar el inventario de la tienda TecnoPunto.

Permite registrar tres productos, validar sus datos y mostrar la información correspondiente.

Utiliza programación orientada a objetos mediante una clase llamada Producto, que contiene propiedades, un constructor y un método para mostrar información.

 Datos de entrada

El programa solicita los siguientes datos:

- Código del producto.
- Nombre del producto.
- Precio del producto.
- Cantidad disponible.

Datos que procesa

El programa realiza las siguientes operaciones:

- Comprueba que el nombre no esté vacío.
- Verifica que el precio sea mayor que cero.
- Comprueba que la cantidad no sea negativa.
- Crea tres objetos de la clase Producto.
- Calcula el valor total de cada producto.

Fórmula:

ValorTotal = Precio × Cantidad

 Datos de salida

El programa muestra:

- Código.
- Nombre.
- Precio unitario.
- Cantidad disponible.
- Valor total en existencia.

También presenta mensajes cuando los datos introducidos son incorrectos.

Validaciones

- Nombre vacío: no permitido.
- Precio negativo o igual a cero: no permitido.
- Cantidad negativa: no permitida.
- Cantidad igual a cero: permitida.

Cuando se introduce un dato inválido, el programa muestra un mensaje y permite volver a introducir la información.
